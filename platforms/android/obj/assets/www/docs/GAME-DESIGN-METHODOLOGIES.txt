GAME DESIGN METHODOLOGIES — LIMEDRIVE CHEATSHEET
================================================

ПЛАТФОРМЕР
----------

Закон трёх прыжков:
  Сначала покажи препятствие. Потом покажи решение. Потом заставь повторить.
  Никогда не требуй больше одного навыка одновременно (кроме финальных уровней).

Чек-лист:
  [ ] Герой может вернуться назад?
  [ ] Каждый прыжок тестится 3 способами: правый край, левый край, по центру
  [ ] Coyote time >= 0.1с — иначе кажется что кнопка не сработала
  [ ] Визуальная подсказка перед каждым новым механизмом
  [ ] Kill zone всегда видна или предсказуема
  [ ] Скорость героя < ширина самого узкого прохода x 2
  [ ] Фрикамп (безопасная зона) каждые 3-5 экранов

Ритм уровня:
  Тихий участок (2 экрана) -> Напряжение (3) -> Развязка (1) -> Награда (чекпоинт)


ГОЛОЛОМКА
---------

Закон одного правила:
  Каждый уровень = одно новое правило. Не два.
  Правило должно быть очевидным из визуала или первого взаимодействия.

Чек-лист:
  [ ] Решение можно найти методом тыка? Если да — правило недостаточно ясно
  [ ] Есть >= 3 способов решить задачу? Если 1 — это загадка, не головоломка
  [ ] Таймер лишний (кроме speedrun-головоломок)
  [ ] Подсказка доступна через 60с бездействия
  [ ] Каждый объект в уровне участвует в решении
  [ ] Сложность растёт по спирали: новое -> комбинация -> новая комбинация
  [ ] Последний уровень = все правила вместе

Кривая сложности:
  Уровень 1-3:   Tutorial (одно правило)
  Уровень 4-7:   Combo (два правила)
  Уровень 8-10:  Twist (правило наоборот)
  Уровень 11-12: Marathon (всё вместе)


ШУТЕР
-----

Правило треугольника:
  Три типа угроз: наземные, воздушные, статичные.
  Каждый бой = минимум 2 типа одновременно.

Чек-лист:
  [ ] Базовое оружие сбалансировано: можно пройти весь уровень без апгрейдов
  [ ] Каждое оружие уникально по механике, не только по числу
  [ ] Враги видны до того, как начнут стрелять (>= 1 секунда)
  [ ] Босс = сумма механик уровня. Ничего нового в финальном боссе
  [ ] Pattern врагов имеет телеграф (предсмертная анимация/поза)
  [ ] Crate/health box каждые 2-3 волны
  [ ] Screen shake < 0.3с — иначе тошнит

Волновая структура боя:
  Волна 1:  Мелкие враги (тест прицеливания)
  Волна 2:  Мелкие + статичные (тест позиционирования)
  Волна 3:  Элитные + мелкие (тест приоритетов)
  Босс:     Всё вместе


RPG
---

Закон прогрессии:
  Герой должен чувствовать рост каждые 15 минут.
  Если прогрессия незаметна — ты делаешь MMO, а не RPG.

Чек-лист:
  [ ] 3 класса персонажей minimum (воин/маг/лекарь или аналог)
  [ ] Диалоги не лор. Диалоги = выбор. Выбор = последствие
  [ ] Экипировка влияет на механики, не только на числа
  [ ] Каждая локация = новый тип врага или среда
  [ ] Квесты: 30% сражения, 30% исследования, 40% выбор/диалог
  [ ] Save point каждые 20 минут. Автосохранение перед боссом
  [ ] XP баланс: 1 уровень = 2-3 боя. Больше — grind, меньше — rush

Структура RPG-уровня:
  Локация -> NPC с квестом -> Исследование -> Бой/Головоломка -> Награда
                                                        -> NPC возвращает -> Сюжетный крючок


ГОНКА
-----

Правило руля:
  Управление должно работать с 2 кнопками (газ + тормоз/поворот).
  Сложность = трасса, не управление.

Чек-лист:
  [ ] Трасса читается за 1 взгляд: видно все повороты на 2 экрана вперёд
  [ ] Бустер = награда за риск. Не за правильный маршрут
  [ ] Адаптивный ИИ: 1-е место = сложнее, последнее = легче
  [ ] Collision detection с OTHER cars, не с стенами (стены = смерть = раздражает)
  [ ] Каждый круг = новая механика (препятствие, буст, ловушка)
  [ ] Лучшее время = replayable. Таблица рекордов обязательна
  [ ] Drag racer: ускорение плавное. Нет instant-стопа

Дизайн трассы:
  Старт -> Прямая (разгон) -> Поворот 90 (тормоз) -> Узкий участок (точность)
  -> Буст-зона (награда) -> Серпантин (мастерство) -> Финиш


УНИВЕРСАЛЬНЫЕ ПРИНЦИПЫ
-----------------------

5 секунд:
  Если игрок не понял что делать через 5 секунд — ты проиграл.
  Тестируй: дай другу игру. Секундомер. Если > 5 сек — пересмотри.

Juice it or lose it:
  Каждое действие = визуальный + звуковой фидбек.
  Нет фидбека -> действие кажется багом.

Ceiling — Floor:
  Ceiling: насколько хорошо может играть профи.
  Floor: насколько плохо может играть новичок.
  Разница не должна быть > 10x.

Tension — Release:
  Напряжение (бой, головоломка, гонка) -> Release (чекпоинт, награда, cutscene).
  Без release -> burnout. Без tension -> скука.

One more try:
  Смерть должна ощущаться как твоя ошибка, не как баг.
  Respawn < 1 секунды. Always.
