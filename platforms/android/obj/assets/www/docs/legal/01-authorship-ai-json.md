# Авторское право на ИИ-генерацию игр в LimeDrive

> Документ носит информационный характер и не является юридической консультацией.
> Для споров и сделок привлекайте юриста по ИТ-праву.

## Вопрос 1. Принадлежит ли автору промпта право на сгенерированный JSON?

Короткий ответ: **не автоматически**. Зависит от степени творческого участия человека.

Правовая база (РФ):

- **Ст. 1257 ГК РФ** — автор произведения только гражданин, *творческим трудом* которого оно создано.
- **П. 80 Постановления Пленума ВС РФ № 10 от 23.04.2019** — охраняются результаты только творческого труда человека; объекты, созданные техническими средствами без творческого вклада человека, авторским правом не охраняются.
- **Судебный прецедент (2023, Москва)** — суд признал охраноспособным изображение, созданное через Midjourney: истец задавал серию промптов, отбирал и комбинировал результаты. Творческий вклад увидели именно в *селекции и итерациях*, а не в одном запросе.

Применительно к LimeDrive:

| Сценарий | Охрана JSON авторским правом | Правообладатель |
|---|---|---|
| Один промпт -> готовый файл без правок | Скорее нет (чистый вывод машины) | Нет |
| Серия промптов + отбор вариантов + правки уровней/параметров | Вероятно да (по модели прецедента) | Автор промптов и правок |
| Ручное написание JSON без генератора | Да | Написавший |

## Что именно и чем охраняется

| Объект | Охрана |
|---|---|
| Текст промпта | Да, как литературное произведение (автоматически) |
| Формат/схема JSON движка | Нет: форматы и интерфейсы не охраняются (п. 6 ст. 1259 ГК РФ) |
| Конкретная конфигурация уровней/баланса | Спорно; возможна охрана как часть аудиовизуального/составного произведения при творческом характере |
| Код движка LimeDrive | Да, автоматически у разработчика движка |
| Игровая механика, правила | Нет (идеи не охраняются) |

## Вопрос 2. Можно ли наложить ограничение на использование вариаций?

Авторским правом — только если вариация подпадает под охрану (см. таблицу выше). Но есть второй механизм:

### Договорные ограничения (рабочий способ)

По ст. 421 ГК РФ (свобода договора) владелец движка вправе выдать LimeDrive по лицензии (EULA) с любыми условиями использования результатов генератора. Договор работает между сторонами даже там, где авторское право бессильно. Примеры формулировок:

```
1. Материалы, сгенерированные Генератором LimeDrive, передаются Пользователю
   по неисключительной лицензии с правом модификации.
2. При коммерческом использовании Пользователь обязан указать:
   «Создано на движке LimeDrive».
3. Пользователю запрещено создавать конкурирующие генераторы игр
   на основе структуры выходных данных Генератора.
4. Исключительная лицензия на созданное произведение предоставляется
   Пользователю только после регистрации программы для ЭВМ / депонирования.
```

Ограничения enforceable через договорный иск; для усиления позиции:

- серверная генерация с логами промптов и версий (доказательство вклада и факта использования);
- техническая метка (watermark-поле `"generator": "limedrive vX.Y"` в JSON);
- регистрация самого движка как программы для ЭВМ (см. `02-evm-registration-limedrive.md`).

## Рекомендации владельцу движка

1. Зафиксировать режим прав на вывод генератора в EULA до публичного запуска.
2. Разделять шаблонную часть JSON (структура движка — ваша) и творческую часть пользователя.
3. Логировать промпты/итерации опционально — это будущие доказательства творческого вклада.
4. В маркетинге не обещать «патент на игру»: корректная формулировка — фиксация авторства и приоритета.
