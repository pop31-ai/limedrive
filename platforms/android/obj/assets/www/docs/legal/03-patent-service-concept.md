# Концепция: сервис регистрации игр LimeDrive («патентоведение как сервис»)

> Не является юридической консультацией и бизнес-планом к действию без проверки.

## Суть идеи

Встроенный в движок сервис, который из JSON-игры пользователя автоматически
готовит полный пакет для государственной регистрации программы для ЭВМ
(Роспатент/ФИПС): реферат, описание, листинг, чек-лист подачи. Пользователь
подаёт заявку сам через Госуслуги/ФИПС; сервис только готовит документы —
поэтому лицензия патентного поверенного не требуется.

Позиционирование честно: НЕ «патент на игру», а **фиксация авторства,
даты приоритета и официальное свидетельство** на игру как программу для ЭВМ.

## Почему работает именно с LimeDrive

- Игра = структурированный JSON. Из него автоматически извлекаются:
  название, жанр, описание механик (settings, components), уровни, ИИ-настройки.
- Генератор документов детерминированный: себестоимость ~0, маржа почти 100%.
- Кнопка «Зарегистрировать игру» прямо в UI движка — уникальная интеграция,
  которой нет у патентных поверенных.

## Ценность для пользователя

| Дает регистрация | Не дает |
|---|---|
| Свидетельство Роспатента, запись в Реестре | Патента на механику (его не существует) |
| Фиксацию приоритета для споров | Защиту от независимого создания похожей игры |
| Актив для грантов, инвесторов, портфолио | Монополию на жанр |

## Модель монетизации (freemium)

| Уровень | Что входит | Цена |
|---|---|---|
| Free | SHA-256 хеш-фиксация JSON с меткой времени (локально) | 0 |
| Base | Автопакет документов (реферат, описание, листинг, чек-лист) | ~1–3 тыс. руб. |
| Pro | + депонирование у стороннего сервиса, помощь при запросах экспертизы | ~5–10 тыс. руб. |
| B2B API | Пакетная генерация для студий/образовательных программ | договорная |

Пошлина Роспатента оплачивается заявителем напрямую (сервис её не трогает).

## Конкуренты и отличие

- Патентные поверенные (ручная работа, от 15–30 тыс. руб.) — мы дешевле за счёт автоматизации.
- Сервисы блокчейн-депонирования (depo.digital, IREG и аналоги) — быстрая фиксация,
  но без госпреюмпции; можно стать партнёром вместо конкурента (уровень Pro).

## Риски и митигация

| Риск | Митигация |
|---|---|
| Восприятие как «юруслуги» | Дисклеймер «техническая подготовка документов; подача — заявителем»; не консультировать по праву индивидуально |
| Отказ/запросы ФИПС из-за качества реферата | Шаблоны из `02-evm-registration-limedrive.md`; ревизия генератора по фидбеку |
| Ошибка в данных заявителя | Чек-лист самопроверки перед выгрузкой пакета |
| Низкая воспринимаемая ценность | Прозрачное сравнение «регистрация vs патент» на лендинге |

## Спецификация API-модуля v0

Модуль: `generator/patent-docs/` (без внешних зависимостей).

```
POST /api/patent/package
  body: { gameJson, author: { name, contacts }, engineVersion }
  -> { referat, descriptionMd, listingTxt, checklist[], fees[] }

POST /api/patent/deposit-hash
  body: { gameJson }
  -> { sha256, timestamp }        // локальная фиксация приоритета

GET  /api/patent/checklist
  -> пошаговый чек-лист подачи (Госуслуги / online.fips.ru)
```

Генераторы:

- `referat.js` — name/description/type/settings -> реферат до 700 знаков;
- `description.js` — модули движка + параметры игры -> описание по структуре ГК/ФИПС;
- `listing.js` — gameJson + версия движка -> депонируемый текст с нумерацией;
- `fees.js` — таблица пошлин (обновляемая конфигурация);
- `hash.js` — канонизация JSON (сортировка ключей) -> SHA-256.

Интеграция: кнопка в `limedrive-ui.js` -> окно экспорта пакета (.zip: docx/md/txt).
