--- 1. РЕФЕРАТ ---

Программа для ЭВМ «LimeDrive» предназначена для исполнения двухмерных
и изометрических трёхмерных игр, описываемых декларативным JSON-форматом.
Область применения: разработка инди-игр, образовательный геймдев,
процедурная генерация игровых уровней. Программа реализует ECS-архитектуру
(15 встроенных компонентов, 12 систем), физику с гравитацией, трением
и сопротивлением среды, обнаружение столкновений, рендеринг средствами
HTML5 Canvas (2D и изометрическая проекция), игровой ИИ на основе алгоритма
минимакс с контратакующими стратегиями, адаптивной сложностью и личностями
противников, оконный интерфейс пользователя, конечный автомат состояний игры
и загрузчик уровней из JSON. Реализована на языке JavaScript без внешних
зависимостей; объём исходного кода около 3000 строк. Для работы требуется
браузер с поддержкой HTML5 Canvas.

--- 2. ОПИСАНИЕ ---

1. ОБЩИЕ СВЕДЕНИЯ
   Название: LimeDrive, версия 1.0.0. Язык: JavaScript (без внешних
   зависимостей). Класс: игровые движки / генераторы игр.

2. НАЗНАЧЕНИЕ
   Исполнение и генерация игр из декларативного JSON-описания;
   применение в инди-геймдеве и образовании.

3. СТРУКТУРА
   Ядро        limedrive-core.js        ~630 строк  ECS, события, физика,
                                                    ввод, коллизии, JSON-загрузчик
   Рендерер    limedrive-3d.js          ~430        изометрия, камера, меши,
                                                    частицы, освещение
   ИИ          limedrive-ai.js          ~360        минимакс, контратака,
                                                    личности, сложность
   Компоненты  limedrive-components.js  ~480        15 встроенных компонентов
   Системы     limedrive-systems.js     ~500        12 встроенных систем
   UI          limedrive-ui.js          ~640        Canvas-виджеты интерфейса

4. ИСПОЛЬЗУЕМЫЕ АЛГОРИТМЫ
   ECS-разделение данных и поведения; коллизии по AABB; минимакс с оценкой
   позиций и контратакующими стратегиями; адаптивная сложность; процедурная
   расстановка сущностей; изометрическая проекция с сортировкой по глубине.

5. ВХОДНЫЕ/ВЫХОДНЫЕ ДАННЫЕ
   Вход: JSON-описание игры (уровни, сущности, камеры, настройки физики
   и ИИ). Выход: исполняемая игровая сессия в браузере.

6. ТРЕБОВАНИЯ К СРЕДЕ
   Браузер с поддержкой HTML5 Canvas; внешние зависимости отсутствуют.
