# Досудебное разрешение споров и снижение судебных рисков

Расширяет п. 7 базовой лицензии (`05`) и общие положения (`06`, О1–О5).
Цель документа: чтобы спор либо не возникал, либо решался без суда.
Не является юридической консультацией; тексты ниже — проект для проверки юристом.

## Принцип: убирать предмет спора до того, как он стал иском

Судебная «драка» возможна только там, где есть неясность. Поэтому лицензионный
комплект закрывает её в четыре слоя:

| Слой | Инструмент | Что устраняет |
|---|---|---|
| 1. Ясность | Матрица прав (ниже) | Споры «а я думал можно» |
| 2. Автоматика | Реестр хеш-фиксаций | Споры о приоритете каталога — решает дата, а не юрист |
| 3. Процедура | Претензионный порядок + медиация | Эмоциональные эскалации |
| 4. Юрисдикция | Третейская оговорка для договорных требований | Гос. суд как первый instinct |

## Матрица прав (разъяснение сторонам)

**Можно без всяких вопросов:**
- играть, стримить, снимать видео, монетизировать канал аудиторией;
- создавать любое число игр; модифицировать движок для себя;
- участвовать в джемах и конкурсах;
- преподавание по EDU-редакции, включая платные курсы.

**Нужно одно действие (уведомление/атрибутация):**
- публикация игры — добавить «Создано на движке LimeDrive»;
- коммерция по NC — перейти на базовую лицензию уведомлением;
- показ студенческих игр учреждением — указать автора.

**Запрещено (единственный источник реальных претензий):**
- продавать/выдавать движок за свой; удалять атрибуцию;
- клонировать генератор на структуре выходных данных;
- требовать уступки прав учащихся как условие обучения.

Правило толкования: все сомнения трактуются в пользу разрешения действия,
если оно не входит в запретительный список.

## Пять ступеней разрешения конфликта

1. **Автоправило** — спор о приоритете в каталоге решается реестром: младшая
   дата хеша получает привилегию. Никаких заседаний.
2. **Переговоры** — обращение в поддержку платформы, срок обсуждения 7 дней.
3. **Претензия** — письменная, по шаблону ниже; ответ обязателен за 10 рабочих
   дней; молчание = отказ.
4. **Медиация** — обязательна до суда/третейского суда, срок до 30 дней,
   расходы пополам.
5. **Юрисдикция** — только после ступени 4.

## Третейская оговорка и её честные границы

В лицензию включается оговорка:

```
Все договорные споры из настоящей лицензии, не урегулированные претензионным
и медиативным порядком, передаются на рассмотрение Международного коммерческого
арбитражного суда при ТПП РФ (или альтернативно: Арбитражного центра при
РСПП) в соответствии с его регламентом. Решение третейского суда окончательно.
```

Границы, которые нельзя обойти (важно знать заранее):

- **Споры о существовании прав на результат ИД** (кто автор по существу) не
  могут передаваться в третейский суд по законодательству РФ об арбитраже —
  они идут в СИП/общие суды. Поэтому лицензия сознательно оформляет все
  взаимные требования как **договорные (лицензионные)** — такие арбитрабельны.
- **Потребительские споры физлиц**: закон о защите прав потребителей даёт
  потребителю право на суд по месту жительства; оговоркой это не отрезается.
- **Недействительность самой лицензии**, банкротство, взыскание с государства —
  вне третейской оговорки.

## Защита самого правообладателя от судебных проблем

```
1. Движок предоставляется «как есть»; Правообладатель не гарантирует
   отсутствие ошибок и пригодность для целей пользователя.
2. Правообладатель не проверяет и не гарантирует, что созданные пользователями
   игры не нарушают права третьих лиц; ответственность за контент — на авторе.
3. Совокупная ответственность Правообладателя ограничена суммой, уплаченной
   пользователем за 12 месяцев (по бесплатной лицензии — ноль).
4. Пользователь возмещает Правообладателю потери, возникшие из претензий
   третьих лиц к играм и контенту пользователя (индемнити).
5. Пользователь подтверждает, что ознакомился с дисклеймером неуникальности
   генераций и не будет основывать требования на одном лишь совпадении.
```

## Шаблоны

### Претензия

```
Кому: [Правообладатель], От: [ФИО, id пользователя, контакт]
ПРЕТЕНЗИЯ (досудебная) по лицензии LimeDrive [редакция]
1. Обстоятельства: [что произошло, даты, id игр].
2. Доказательства: [хеши фиксации, даты в Реестре, логи промптов].
3. Норма лицензии: [пункт].
4. Требование: [что именно просите, в какой срок].
Приложения: [...].  Дата, подпись.
```

### Ответ на претензию (выбирается один)

```
А) Признаю; исполню требование до [дата].
Б) Отклоняю по причине: [пункт лицензии / данные Реестра]. 
В) Предлагаю компромисс: [условия]. Молчание свыше 10 рабочих дней
считается отклонением и открывает ступень медиации.
```

## Внедрение

- Включить разделы «Матрица прав» и «Третейская оговорка» в тексты всех трёх
  редакций лицензий (05, 06).
- Шаблоны претензии/ответа — на сайт проекта и в поддержку платформы.
- Реестр хешей технически — `registry.js` из `04-collision-resolution.md`.
