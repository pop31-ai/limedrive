# Сводная IP-политика LimeDrive (мастер-документ)

Итог всех обсуждений. Коротко: что решено, где подробности. Не является
юридической консультацией.

## Позиционирование проекта

LimeDrive — **бесплатный** вариативный игровой движок: забавная разработка
и управление играми через ИИ по промпту (JSON -> игра). Цель — копилка игр,
а не распыление шедевров.

## Решённые вопросы

| # | Вопрос | Решение | Документ |
|---|---|---|---|
| 1 | Чьё право на JSON, сгенерированный ИИ по промпту? | Не автоматически у автора промпта; охраняется только творческий вклад (итерации, правки, компоновка). Чистый вывод ИИ скорее не охраняется | `01-authorship-ai-json.md` |
| 2 | Ограничение вариаций | Авторским правом нельзя — договором (EULA) можно; примеры формулировок готовы | `01-authorship-ai-json.md` |
| 3 | Совпадение генераций у двух игроков | Отраслевой стандарт: права передаются пользователю + дисклеймер неуникальности + платформа не судит споры. Претензия из одного совпадения ничтожна | `04-collision-resolution.md` |
| 4 | Разруливание конфликтов | Механизм «Приоритет фиксации»: реестр хешей, логи независимости, зона несравнения шаблонов, претензионный порядок | `04-collision-resolution.md` |
| 5 | Регистрация движка | Регистрация программы для ЭВМ в Роспатенте (~3–5 т.р., ~2 мес.); черновики реферата и описания готовы | `02-evm-registration-limedrive.md` |
| 6 | Сервис регистрации игр пользователей | Жизнеспособен; НЕ «патентование», а автоподготовка пакета документов из JSON; API-спека готова | `03-patent-service-concept.md` |
| 7 | Лицензия бесплатного движка | Кастомная freeware-лицензия (атрибутация + запрет клонов генератора); альтернатива MIT если нужен настоящий open source | `05-eula-free-engine.md` |
| 8 | Некоммерческая и образовательная редакции | NC: без коммерции, апгрейд в базовую уведомлением; EDU: учебный процесс бесплатно, права учащихся — учащимся | `06-licenses-nc-edu.md` |
| 9 | Копилка генераций | Регламент пополнения `games/`: каждая игра = game.json + meta.json (промпты, хеш, авторство) | `../../games/README.md` |

## Порядок действий до публичного запуска

1. Внести EULA (`05`) в дистрибуцию движка и на сайт.
2. Подать заявку на регистрацию программы для ЭВМ (`02`).
3. Начать вести реестр хеш-фиксаций игр (`04`, `06`-модули — по мере реализации).
4. Наполнить копилку первыми играми по регламенту (`games/README.md`).
