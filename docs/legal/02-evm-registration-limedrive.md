# Регистрация LimeDrive как программы для ЭВМ: пакет документов и процедура

> Не является юридической консультацией. Актуальные пошлины и формы проверяйте
> на портале ФИПС (new.fips.ru) и Госуслуг перед подачей.

## Что это даёт

- Свидетельство Роспатента — официальная фиксация авторства и даты приоритета.
- Запись в Реестре программ для ЭВМ.
- Презумпция правообладания в спорах; удобный актив для инвесторов/грантов.
- ВАЖНО: это **не патент**. Исключительное право возникает у вас автоматически
  с момента создания кода; регистрация лишь удостоверяет его.

## Пошаговая процедура

1. Подготовить материалы (см. черновики ниже):
   - реферат (до ~700 знаков);
   - описание программы;
   - депонируемый листинг (можно частично — первые/ключевые листинги);
   - анкету-заявление по форме ФИПС.
2. Получить подтверждённую учётную запись Госуслуг (УКЭП не обязательна,
   но ускоряет онлайн-подачу).
3. Уплатить пошлины (ориентир суммарно порядка 3–5 тыс. руб. для физлица;
   точные суммы — калькулятор пошлин на new.fips.ru).
4. Подать заявку:
   - через онлайн-портал ФИПС (online.fips.ru), или
   - через Госуслуги (услуга «Государственная регистрация программы для ЭВМ»).
5. Дождаться формальной экспертизы (~1–2 мес.). При запросе — направить ответ
   в течение срока из запроса.
6. Получить свидетельство; данные внесут в Реестр.

Срок действия исключительного права: жизнь автора + 70 лет.

## Черновик реферата

```
Программа для ЭВМ «LimeDrive» предназначена для исполнения двухмерных и
изометрических трёхмерных игр, описываемых декларативным JSON-форматом.
Область применения: разработка инди-игр, образовательное геймдев,
процедурная генерация игровых уровней. Программа реализует ECS-архитектуру
(15 встроенных компонентов, 12 систем), физику с гравитацией, трением и
сопротивлением среды, обнаружение столкновений, рендеринг средствами
HTML5 Canvas (2D и изометрическая проекция), игровой ИИ на основе алгоритма
минимакс с контратакующими стратегиями, адаптивной сложностью и личностями
противников, оконный интерфейс пользователя, конечный автомат состояний игры
и загрузчик уровней из JSON. Реализована на языке JavaScript без внешних
зависимостей; объём исходного кода около 3000 строк. Для работы требуется
браузер с поддержкой HTML5 Canvas.
```

## Черновик описания (структура)

1. **Общие сведения**: название LimeDrive, версия 1.0.0, язык JavaScript,
   класс — игровые движки/генераторы игр.
2. **Назначение**: исполнение и генерация игр из декларативного описания.
3. **Структура** (из docs/README.md):

   | Модуль | Файл | Объём | Назначение |
   |---|---|---|---|
   | Ядро | limedrive-core.js | ~630 строк | ECS, события, физика, ввод, коллизии, JSON-загрузчик |
   | Рендерер | limedrive-3d.js | ~430 | Изометрия, камера, меши, частицы, освещение |
   | ИИ | limedrive-ai.js | ~360 | Минимакс, контратака, личности, сложность |
   | Компоненты | limedrive-components.js | ~480 | 15 встроенных компонентов |
   | Системы | limedrive-systems.js | ~500 | 12 встроенных систем |
   | UI | limedrive-ui.js | ~640 | Canvas-виджеты интерфейса |

4. **Используемые алгоритмы**: ECS-разделение данных и поведения; sweep-and-prune
   / AABB коллизии; минимакс с альфа-бета отсечением (уточнить по коду);
   процедурная расстановка сущностей.
5. **Входные/выходные данные**: JSON-описание игры (см. PROMPT.md); вывод —
   исполняемая игровая сессия в браузере.
6. **Требования к техническим средствам**: браузер с HTML5 Canvas, ~2 МБ ОЗУ
   на сессию (оценить фактически).

## Частые причины запросов экспертизы

- Реферат не отражает назначение и характеристики — используйте шаблон выше.
- Листинг нечитаем (нужен печатный вид, нумерация страниц).
- Расхождение названия в заявлении и материалах.
- Неполная оплата пошлин.
