# Lesson 2: Tools & Techniques

## 🇷🇺 Урок 2: Инструменты и техники

### Tool Overview

| Tool | Best For | Opacity Tip |
|------|----------|-------------|
| **Pen** 🖊 | Lines, outlines, calligraphy | 100% for solid lines |
| **Brush** 🖌 | Shading, soft edges, painting | 40-70% for blending |
| **Marker** 🖍 | Fills, gradients, backgrounds | 20-40% for layering |
| **Airbrush** 💨 | Textures, glow effects, fog | 10-30% for buildup |
| **Eraser** 🧹 | Corrections, effects | 100% to erase |

### Size & Opacity Control

- **Slider** in toolbar for precise control
- Brush size: 1px (detail) to 60px (broad strokes)
- Opacity: 5% (faint) to 100% (solid)

### Technique: Line Weight

```
Thin (1-3px)    ───  Details, hair, textures
Medium (4-12px) ───  Main outlines, writing
Thick (15-60px) ───  Fills, bold strokes, blocking
```

### Technique: Blending

1. Set Brush opacity to 40%
2. Lay down base color
3. Overlap with second color
4. Repeat for smooth transitions
