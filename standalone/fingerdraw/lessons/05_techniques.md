# Lesson 5: Advanced Drawing Techniques

## 🇷🇺 Урок 5: Продвинутые техники

### 1. Value Sketching

Use low-opacity brush (20-30%) to build up values gradually:

```
Step 1: Rough block-in   ░░░░░░░░░░
Step 2: Mid-tones        ░░▒▒▒░░░░░
Step 3: Shadows          ░░▒▒▓▓░░░░
Step 4: Highlights       ▒▒▒▒▓▓░░░░
Step 5: Refine           ▒▓▓▓▓▓▒░░░
```

### 2. Color Blending

With Airbrush at 15% opacity:
1. Base layer: solid mid-tone
2. Airbrush shadows with darker hue
3. Airbrush highlights with lighter hue  
4. Blend edges with medium hue at 20%

### 3. Selection-Assisted Drawing

1. Select an area with selection tool
2. Draw only within selection boundaries
3. Clear selection when done
4. Perfect for keeping edges clean

### 4. Zoom Window Technique

- Keep zoom view active for precision
- Watch the 4× zoom while drawing
- Great for: eyes, lips, small details

### 5. Layer-Based Shading

```
Layer setup for a sphere:
├── Base (solid mid-tone circle)
├── Shadow (darker arc, 60% opacity)
├── Highlight (white crescent, 40%)
├── Reflection (light blue crescent, 20%)
└── Glow (soft radial, 15%)
```

### 6. Texture Creation

- **Airbrush spatter**: low opacity, medium size, quick taps
- **Cross-hatching**: Pen tool, thin lines at angles
- **Stippling**: Pen tool, tiny dots, varying density
- **Smudge effect**: Brush with very low opacity, overlapping strokes

### Exercise 5: Value Study

1. Draw a simple sphere using only 4 value levels
2. Start with the darkest shadow
3. Build up to mid-tones
4. End with highlights
5. Try the same in color

## 🇬🇧 Урок 5: Продвинутые техники

### 1. Светотень (Value Sketching)

Используйте низкую непрозрачность (20-30%) для постепенного набора тона.

### 2. Цветовое смешение

Аэрограф с 15% непрозрачностью для плавных переходов.

### 3. Рисование с выделением

Выделите область → рисуйте только внутри → идеальные края.

### 4. Техника Zoom-окна

Следите за 4× увеличением при рисовании мелких деталей.

### 5. Слои для объёмных форм

Отдельные слои для базы, тени, блика, отражения, свечения.

### 6. Создание текстур

- **Набрызг**: аэрограф, быстрые касания
- **Штриховка**: Pen, тонкие линии под углом
- **Пуантилизм**: Pen, точки разной плотности

### Упражнение 5: Изучение тона

Нарисуйте сферу, используя 4 уровня тона: от тени до блика.
