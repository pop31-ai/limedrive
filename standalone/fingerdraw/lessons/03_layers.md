# Lesson 3: Working with Layers

## 🇷🇺 Урок 3: Работа со слоями

### Why Layers?

Layers let you separate different elements of your drawing:
- **Background** — canvas color, gradients
- **Sketch** — rough lines, guide shapes
- **Colors** — base colors on separate layers
- **Details** — highlights, shadows, textures
- **Effects** — glow, overlay effects

### Layer Panel

Tap **📑** in toolbar to open layer panel.

```
┌─────────────────────┐
│ Layers              │
├─────────────────────┤
│ 👁 Sketch     [act] │
│ 👁 Colors           │
│ 👁 Background       │
├─────────────────────┤
│ [+ Add Layer]       │
└─────────────────────┘
```

### Layer Controls

| Control | Action |
|---------|--------|
| 👁 tap | Toggle visibility |
| Layer tap | Set as active |
| Order drag | Reorder layers |

### Technique: Non-Destructive Workflow

1. **Sketch layer** — rough shapes at low opacity
2. **Base layer** — flat colors
3. **Detail layer** — shading and texture
4. **Effects layer** — highlights, glow

This way you can erase or modify any aspect without affecting others.

### Exercise 3: Layer Portrait

1. Add 3 layers: "Sketch", "Colors", "Details"
2. Draw a simple face on Sketch (low opacity)
3. Fill colors on Colors layer
4. Add details on Details layer
5. Toggle visibility to see each layer's contribution

## 🇬🇧 Урок 3: Работа со слоями

### Панель слоёв

Нажмите **📑** чтобы открыть панель слоёв.

### Техника: Бесконфликтный рабочий процесс

1. **Скетч** — грубые формы с низкой непрозрачностью
2. **База** — плоские цвета
3. **Детали** — тени, текстуры
4. **Эффекты** — блики, свечение

### Упражнение 3: Портрет слоями

1. Создайте 3 слоя: «Скетч», «Цвета», «Детали»
2. Нарисуйте лицо на «Скетч»
3. Закрасьте на «Цвета»
4. Добавьте детали
5. Включайте/выключайте слои
