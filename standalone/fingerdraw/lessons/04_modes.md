# Lesson 4: Drawing Modes Deep Dive

## 🇷🇺 Урок 4: Режимы рисования

### Mode Comparison

```
Precise Mode                    Visible Mode
┌──────────────────┐           ┌──────────────────┐
│                  │           │                  │
│   [Magnified]    │           │    ✎ drawing     │
│   view above     │           │    here          │
│   finger         │           │                  │
│                  │           │   ● finger       │
│   ● finger       │           │   here           │
│                  │           │                  │
└──────────────────┘           └──────────────────┘
```

### Precise Mode — When to Use

- **Fine details** — eyes, small text, intricate patterns
- **Precision work** — tracing, exact lines
- **Small canvas** — when working in tight spaces

The magnifier shows a 3× zoomed view above your finger.
A crosshair marks the exact drawing point.
The brush cursor shows actual size on the zoomed view.

### Visible Mode — When to Use

- **Broad strokes** — shading large areas
- **Composition** — seeing the big picture
- **Gestural drawing** — loose, expressive marks

The drawing is offset ~100px above your finger.
A dotted line connects finger to drawing point.
A blue circle shows where the stroke will appear.

### Switching Modes

Tap **mode toggle** button in the toolbar (shows current mode).

### Exercise 4: Mode Mastery

1. Switch to **Precise Mode**
2. Draw a detailed eye (use magnifier for iris detail)
3. Switch to **Visible Mode**
4. Add shading around the eye
5. Compare: precise control vs. visible flow

### Pro Tips

- Use **Precise Mode** for starting and refining
- Use **Visible Mode** for filling and blending
- Combine both in one drawing for best results
- Adjust brush size smaller in Precise Mode

## 🇬🇧 Урок 4: Режимы рисования

### Precise Mode (Точный режим)

- 3× увеличение области под пальцем
- Перекрестие указывает точную точку рисования
- Для деталей, мелких элементов

### Visible Mode (Видимый режим)

- Рисунок смещён на ~100px вверх
- Пунктир соединяет палец и точку рисования
- Для широких штрихов, заливки, композиции

### Упражнение 4: Освоение режимов

1. Переключитесь в Precise Mode
2. Нарисуйте детальный глаз
3. Переключитесь в Visible Mode
4. Добавьте тени вокруг глаза
5. Сравните результаты
