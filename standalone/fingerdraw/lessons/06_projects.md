# Lesson 6: Complete Projects

## 🇷🇺 Урок 6: Проекты

### Project 1: Minimal Landscape

**Goal:** Create a sunset landscape using layers and blending.

**Steps:**
1. **Background layer**: Gradient sky (Airbrush, large strokes)
2. **Sun layer**: Circle, solid color, then glow with Airbrush
3. **Mountain layer**: Dark silhouette, Pen tool
4. **Foreground layer**: Trees/grass, Marker at low opacity
5. **Reflection layer**: Flip and blur the landscape below

**Time:** 15-20 minutes

### Project 2: Portrait Sketch

**Goal:** Expressive portrait using only 3 tools.

**Steps:**
1. **Sketch layer**: Pen, thin lines (3px), basic proportions
2. **Shading layer**: Brush, 30% opacity, build face volumes
3. **Detail layer**: Pen, 2px, eyes, nose, mouth lines
4. **Highlights**: Airbrush, 20%, white, cheekbones and nose bridge

**Time:** 30-45 minutes

### Project 3: Pattern Design

**Goal:** Create a repeating pattern.

**Steps:**
1. Small canvas (500×500)
2. Draw motif in center
3. Use selection to copy/move elements
4. Layer multiple motifs
5. Export as PNG for use in other apps

**Time:** 20-30 minutes

### Project 4: Digital Painting

**Goal:** Full-color digital painting with layers.

**Steps:**
1. **Sketch** — rough composition (3 layers)
2. **Base colors** — flat fills (Marker, 50%)
3. **Shadows** — darker hues (Brush, 40%)
4. **Highlights** — lighter hues (Airbrush, 30%)
5. **Details** — sharp lines (Pen, 3px)
6. **Effects** — glow, texture overlays

**Time:** 60-90 minutes

### Project Checklist

Before starting a project:
- [ ] Canvas size chosen
- [ ] Layers planned
- [ ] Color palette ready
- [ ] Mode selected (Precise/Visible)
- [ ] Brush sizes thought out

After finishing:
- [ ] Export as PNG (💾)
- [ ] Review at different zoom levels
- [ ] Check layer visibility
- [ ] Save work
