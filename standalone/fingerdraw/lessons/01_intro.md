# Lesson 1: Getting Started with FingerDraw

## 🇷🇺 Урок 1: Знакомство с FingerDraw

### What is FingerDraw?

FingerDraw is a professional drawing application designed **exclusively for finger use** on tablets. Unlike traditional stylus-based apps, FingerDraw optimizes every interaction for touch — bigger hit targets, offset drawing, and magnified previews.

### Why Finger Drawing?

- **No stylus needed** — draw anywhere, anytime
- **Natural motion** — your finger is the most intuitive tool
- **Accessible** — no extra hardware required

### Installation

1. Open `index.html` in Chrome
2. Tap "Add to Home Screen" to install as PWA
3. Launch from home screen — works offline

### First Drawing

1. Select **Pen** tool (🖊)
2. Choose a color
3. Set size to 8px
4. Drag your finger on the canvas
5. Watch the preview panel show your stroke in detail

### Exercise 1: Warm-up

Draw loops, spirals, and zigzags to get comfortable with finger control.

## 🇬🇧 Урок 1: Первые шаги

### Что такое FingerDraw?

FingerDraw — профессиональное приложение для рисования, созданное **исключительно для пальцев** на планшетах.

### Первый рисунок

1. Выберите **Pen** (🖊)
2. Выберите цвет
3. Установите размер 8px
4. Проведите пальцем по холсту
5. Наблюдайте за превью-панелью

### Упражнение 1: Разминка

Рисуйте петли, спирали и зигзаги, привыкая к управлению пальцем.
