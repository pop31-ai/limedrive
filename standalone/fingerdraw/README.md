## 🇷🇺 О проекте

FingerDraw — профессиональное приложение для рисования пальцем на планшетах.

### Возможности

- **Два режима рисования**: Precise (под пальцем с лупой) и Visible (смещённый, видно всё полотно)
- **Превью-панель**: показывает инструмент и увеличенный участок рисования
- **4× Zoom-окно**: для точной проработки деталей
- **Выделение областей**: просмотр и работа с выбранными участками
- **Слои**: многослойное рисование с управлением видимостью
- **5 инструментов**: Pen, Brush, Marker, Airbrush, Eraser
- **30 шагов истории**: Undo/Redo
- **Экспорт PNG**: сохранение готовой работы

### Быстрый старт

```
git clone https://github.com/pop31-ai/FingerDraw.git
cd FingerDraw
npx serve .
```

Откройте в браузере на планшете → Chrome → "Add to Home Screen"

## 🇬🇧 About

FingerDraw is a professional drawing application designed exclusively for finger use on tablets.

### Features

- **Two drawing modes**: Precise (magnified under-finger view) and Visible (offset drawing)
- **Preview panel**: tool preview + magnified drawing area
- **4× Zoom window**: for fine detail work
- **Selection**: view and manage selected areas
- **Layers**: multi-layer drawing with visibility control
- **5 tools**: Pen, Brush, Marker, Airbrush, Eraser
- **30-step undo/redo**
- **Export PNG**

### Quick Start

```
git clone https://github.com/pop31-ai/FingerDraw.git
cd FingerDraw
npx serve .
```

Open in tablet browser → Chrome → "Add to Home Screen"
