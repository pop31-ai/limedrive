# User Guide — FingerDraw

## 🇷🇺 Руководство пользователя

### Режимы рисования

| Режим | Описание |
|-------|----------|
| **Precise** | Показывает увеличенную область под пальцем. Рисуйте точно, видя каждую деталь сквозь лупу |
| **Visible** | Рисунок смещён относительно пальца. Видно всё полотно, рука не мешает |

**Переключение:** кнопка в тулбаре (слева от размера).

### Инструменты

- **🖊 Pen** — чёткие линии, стандартная кисть
- **🖌 Brush** — мягкая кисть с текстурой
- **🖍 Marker** — полупрозрачный маркер
- **💨 Airbrush** — аэрограф с разбрызгиванием
- **🧹 Eraser** — ластик (стирает пиксели)

### Превью-панель

Показывает:
- Увеличенный участок вокруг пальца
- Текущий инструмент и размер кисти
- Перекрестие для точного позиционирования

### Zoom-окно

4× увеличение области вокруг пальца.
Помогает при тонкой работе (мелкие детали, ретушь).

### Выделение

- Выберите инструмент выделения в тулбаре
- Проведите по холсту — появится рамка
- Информация о выделении отображается на панели
- Используйте для фокусировки на участке

### Слои

- Кнопка «📑» открывает панель слоёв
- Добавляйте новые слои, отключайте видимость
- Активный слой подсвечивается

### Сочетания

| Действие | Как выполнить |
|----------|--------------|
| Отмена | Кнопка ↩ или два пальца (tap) |
| Повтор | Кнопка ↪ |
| Очистить | Кнопка 🗑 |
| Экспорт PNG | Кнопка 💾 |
| Zoom | Щипок двумя пальцами |
| Размер кисти | Ползунок или кнопки +/– |

## 🇬🇧 User Guide

### Drawing Modes

| Mode | Description |
|------|-------------|
| **Precise** | Magnified view under your finger. See every detail through the loupe |
| **Visible** | Drawing is offset from your finger. See the whole canvas without hand blocking |

**Switch:** toolbar button (left of size slider).

### Tools

- **🖊 Pen** — crisp lines, standard brush
- **🖌 Brush** — soft textured brush
- **🖍 Marker** — semi-transparent marker
- **💨 Airbrush** — spray effect
- **🧹 Eraser** — erases pixels

### Preview Panel

Shows:
- Magnified area around your finger
- Current tool and brush size
- Crosshair for precise positioning

### Zoom Window

4× magnification around your finger.
Perfect for fine detail work (retouching, small elements).

### Selection

- Tap selection tool in toolbar
- Drag on canvas — selection rectangle appears
- Selection info shown on panel
- Use to focus on specific areas

### Layers

- "📑" button opens layer panel
- Add layers, toggle visibility
- Active layer is highlighted

### Actions

| Action | How |
|--------|-----|
| Undo | ↩ button or two-finger tap |
| Redo | ↪ button |
| Clear | 🗑 button |
| Export PNG | 💾 button |
| Zoom | Two-finger pinch |
| Brush size | Slider or +/– buttons |
