# 🎲 Кубик-Карты (dice-cards-games)

Настольная игра на HTML-канве для **5 человек**: кубики, карточки заданий, поле-дорожка и рейтинг по времени.

Этот репозиторий — основа стиля **dice-cards-games**: класса живых партийных игр, где есть поле из клеток, кубики с возможностью «подправить ход» (переброс до двух кубиков) и карточки, которые нужно читать вслух и выполнять на время. Стиль построен на простых правилах, мягком соперничестве и честном рейтинге — на него удобно ссылаться и из него удобно вырастают новые игры.

## Как играть

1. Бросай 3 кубика, можешь перебросить до двух из них.
2. Сумма кубиков — сколько шагов делает фишка по дорожке из 36 клеток.
3. На обычной клетке возьми карточку, прочитай её вслух и выполни задание за отведённое время (20–30 секунд).
4. Очки = время выполнения (быстрее — больше, до 10). Пропуск = −2, время вышло = 0.
5. Клетки «+2» и «−2» начисляют очки сразу.
6. Кто первый дошёл до финиша — победитель; при равенстве очков выше пришедший раньше.

## Запуск

Открой `index.html` в браузере — никаких зависимостей и сборки не нужно. В окне старта можно вписать имена пяти игроков.

## Файлы

- `index.html` — разметка и оверлеи старта/финала
- `style.css` — оформление
- `game.js` — вся игровая логика (поле, кубики, карточки, рейтинг)
- `articles/` — 50 статей о стиле dice-cards-games: правила, стиль, подход и применение
