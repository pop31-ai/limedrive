# Дрон-Гонка: Арена (SpeedVes)

Игрушечные дрон-гонки на HTML5 Canvas. Топовый вид со стадиона, игрушечные машинки-дроны, трамплины, покрытия и толкашки.

## Быстрый старт

Открой `index.html` в браузере, нажми «ИГРАТЬ» (или любую клавишу) — и погнали.

## Управление

| Клавиша      | Действие                        |
| ------------ | ------------------------------- |
| `← →` / `A D` | руль                           |
| `↓` / `S`     | тормоз                          |
| `G`          | ТОЛКАШКА: разбег + таран соперника |
| `R`          | реванш на этом же треке         |
| `Enter`      | следующий трек (после финиша)   |
| `M`          | звук вкл/выкл                   |

## Механики

- **30 треков** на одном стадионе с уникальными именами (сиды 0–29).
- **Покрытия**: асфальт, газон, гравий, лёд — разные сцепление и разгон. На льду бот даже «юзит».
- **Трамплины** — на разбеге подкидывают в воздух (винты крутятся), полёт даёт короткое ускорение.
- **Толкашка** (`G`) — разбег и мощный таран: соперники разлетаются, у самого бонус к скорости.
- **Скорость по игровому полю**: ускорения/замедления (`boost`-зоны) и «погладить апсет» — статусные метки: `В ПРЫЖКЕ`, `ПОЛЁТ`, `ЮЗ`, `ПЕРЕВЁРНУЛСЯ`, `ТОЛКАШКА`.
- **ИИ-пилоты** со скилл-уровнями, возгласы (по-русски), реакция на крутые повороты и прямые.
- **Зрители и камеры-дроны** вокруг трассы, миникарта, панель пилота, медальки, финишное табло заезда.

## Файлы

- `index.html` — запуск, стили, заставка
- `core.js` — генерация треков, физика пути, машины, звук
- `render.js` — предрендер трассы (полосы покрытий, трамплины, финиш)
- `sim.js` — симуляция, отрисовка машин/спрайтов, HUD, события, события ввода

## Технические детали

- Предметы/возгласы — канвас-пузыри; состояние `STATE`-строка в HUD.
- Управление по `e.code` (не ломается на не-QWERTY-раскладках).
- Ошибки показываются красным в HUD (`ОШИБКА: …`) вместо тихих зависаний.
